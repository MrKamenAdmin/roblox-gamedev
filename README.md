# Геймдев на Roblox: от идеи до денег

Интерактивный курс о бизнесе и дизайне игр на Roblox, без программирования.

## Как открыть

Онлайн: https://mrkamenadmin.github.io/roblox-gamedev/

Локально: Дважды щёлкните `index.html`. Сервер, сборка и установка не нужны.
Прогресс, ответы квизов, упражнения и концепт хранятся в `localStorage` этого браузера. Если очистить данные сайта, они удалятся.

`tests.html` — самопроверка: расчёты калькулятора и целостность контента. Все строки должны быть зелёными.

## Структура

```
index.html        каркас, подключает файлы по <script>
style.css         вёрстка, светлая и тёмная темы
app.js            навигация, уроки, квизы, прогресс, глоссарий
tools.js          калькулятор, карта жанров, разборы игр, конструктор концепта
content/m01..m10  уроки по модулям
content/glossary.js, genres.js, games.js
```

## Как добавить урок

Откройте нужный `content/mXX.js` и добавьте объект в `lessons`:

```js
{
  id: 'm3-6',                 // уникальный: m<модуль>-<номер>
  title: 'Название',
  minutes: 7,
  verified: '2026-10-21',     // дата проверки фактов
  body: `<p>Текст в HTML…</p>`,
  summary: ['Главное 1', 'Главное 2'],
  quiz: [
    { q: 'Вопрос?', a: [
      { t: 'Вариант', ok: true,  why: 'Почему верно' },
      { t: 'Вариант', ok: false, why: 'Почему нет' },
    ] },
  ],
  sources: [{ title: 'Источник', url: 'https://…' }],
  exercise: {                 // необязательно: «Сыграй и разбери»
    title: '…', intro: '<p>…</p>', questions: ['Вопрос 1', 'Вопрос 2'],
  },
}
```

Урок без `body` показывается в меню как «готовится».

Блоки внутри `body`:

| Класс | Назначение |
|---|---|
| `<div class="note fact">` | факт с источником |
| `<div class="note practice">` | практика сообщества |
| `<div class="note opinion">` | мнение автора курса |
| `<div class="note unknown">` | точных данных нет |
| `<div class="note warn">` | важное предупреждение |
| `<div class="note ru">` | блок «Для России» |
| `<div class="flow"><span>A</span><b>→</b><span>B</span></div>` | схема-поток |
| `<div class="table-wrap"><table>…</table></div>` | таблица |
| `<div class="bars"><div class="b"><span>Подпись</span><div><i style="width:40%"></i></div><span>40%</span></div></div>` | столбики |

Термины из `content/glossary.js` подсвечиваются в тексте автоматически, при первом упоминании. Чтобы добавить термин, допишите `{ term, match, def }`. Звёздочка в `match` (`'удержани*'`) означает «любое окончание».

Новый модуль: создайте `content/mNN.js` по образцу и подключите его в `index.html` и `tests.html`.
